# Fun Benchmarks and Projects

A collection of fun mini-projects built with AI coding agents and models.

## Projects

### 🎮 Quake Game
A browser-playable version of the classic Quake game, generated with the help of coding agents and Kimi K3.

[Check it out →](./quake/README.md)

### 🤖 Cool Kimi K3 Demos
A curated list of cool demos, playable games, simulations, and 3D scenes built with Kimi K3.

[Check it out →](./kimi-k3/README.md)

### 🏇 LLM Derby
A horse race. Three or four models answer the same trivia questions. Each correct answer moves the horse of that model forward. It compares accuracy, speed, and cost. A simulator mode needs no API keys.

🎓 This project now has its [own repo](https://github.com/sujee/llm-derby). [Play live →](https://sujee.github.io/llm-derby)

### 🐍 LLM Snake Arena
Two models each control a snake on a shared grid. It compares response speed, reliability, and decision-making.

🎓 This project now has its [own repo](https://github.com/sujee/llm-snake-arena).
