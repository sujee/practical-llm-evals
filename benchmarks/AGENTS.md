# AGENTS.md — benchmarks

Instructions for agents that run benchmarks in this folder. The [root AGENTS.md](../AGENTS.md) rules also apply (writing style, uv, Git).

## Which runbook to follow

| The user asks for | Go to the folder | Runbook |
| --- | --- | --- |
| A speed test or a load test | `perf/` | [perf/AGENTS.md](./perf/AGENTS.md) |
| A quality test | `quality/` | [quality/AGENTS.md](./quality/AGENTS.md) |
| The meaning of a metric | | [vocabulary-and-methodology.md](./vocabulary-and-methodology.md) |

Each project has its own `.env` file. Start at the `README.md` of the project folder.

The rules for secrets, cost, and reports are in the runbook of each project. Follow the runbook in the folder where you work.
