# Practical LLM Evals

Hands-on benchmarks, performance tests, and visual explorations for LLMs.

## Benchmark your inference endpoint

Test the speed, quality, and load behavior of an OpenAI-compatible endpoint. 

These benchmarks are agent-first: each one has a runbook (`AGENTS.md`) that a coding agent can follow. You can also run them by hand.

[Start here: benchmarks/README.md →](./benchmarks/README.md)

## Fun eval tools

Games that compare models by how they play. Both have their own repos.

- 🏇 [LLM Derby](https://github.com/sujee/llm-derby) — models race when they answer trivia. It compares accuracy, speed, and cost. [Play live →](https://sujee.github.io/llm-derby)
- 🐍 [LLM Snake Arena](https://github.com/sujee/llm-snake-arena) — two models play Snake against each other. It compares response speed, reliability, and decision-making. [Play live →](https://sujee.github.io/llm-snake-arena)
